## <img src="https://media.giphy.com/media/hvRJCLFzcasrR4ia7z/giphy.gif" width="25" alt="" /> About Arct

Arct Development is a space for creating and maintaining software projects. We value useful ideas, clean implementation, thoughtful details, and learning through building.

Our focus is simple:

- **Build** — turn ideas into working software.
- **Improve** — refine projects through iteration and feedback.
- **Share** — make useful work accessible to the community.
- **Explore** — experiment with tools, technologies, and new approaches.
